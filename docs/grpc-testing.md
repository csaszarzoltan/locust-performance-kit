# gRPC Testing Guide

> Load-test gRPC services using the `GrpcUser` template, part of the
> [Multi-Protocol Templates](../README.md#multi-protocol-templates-v140) (v1.4.0+).

## Overview

gRPC is a high-performance RPC framework that uses HTTP/2 and Protocol Buffers.
It's popular in microservice architectures for its low latency, strong typing,
and streaming capabilities. Load-testing gRPC services requires a client that
understands protobuf serialisation and can manage channel lifecycle, stub
creation, and per-call metadata.

`GrpcUser` wraps a Locust `User` with:

- **Channel management** — creates and caches a single gRPC channel per
  simulated user.
- **Stub caching** — reuses stub instances for the same stub class.
- **Auth integration** — hooks into the pluggable authenticator system so
  per-call metadata (tokens, API keys) is attached automatically.
- **Locust event firing** — every RPC call fires `events.request` with
  `request_type="grpc"`, so metrics appear in the Locust web UI and reports.

## Quick Start

Subclass `GrpcUser`, override `on_start` to configure the target channel and
stub, then write `@task`-decorated methods that call `_call_rpc`.

```python
from locust import between, task
from locust_templates.grpc import GrpcUser

# Generated protobuf classes
from helloworld_pb2 import HelloRequest
from helloworld_pb2_grpc import GreeterStub


class GreeterUser(GrpcUser):
    wait_time = between(1, 3)

    def on_start(self):
        """Connect to the gRPC server and cache the stub."""
        super().on_start()
        self._get_channel("localhost:50051")
        self.stub = self._get_stub(GreeterStub)

    @task
    def say_hello(self):
        """Call SayHello with a fixed request."""
        request = HelloRequest(name="Load Tester")
        self._call_rpc(self.stub.SayHello, request)

    @task
    def say_hello_timeout(self):
        """Call SayHello with a shorter deadline."""
        request = HelloRequest(name="Quick Test")
        self._call_rpc(self.stub.SayHello, request, timeout=2)
```

Run it:

```bash
locust -f my_load_test.py --users 50 --spawn-rate 5 --run-time 5m
```

## API Reference

### `GrpcUser`

Base class: `locust.User`

| Attribute / Method          | Description                                                                    |
|-----------------------------|--------------------------------------------------------------------------------|
| `auth_provider`             | Authenticator provider name (default `"env"`). See [auth docs](auth-startup-hooks.md). |
| `auth_kwargs`               | Keyword arguments passed to the authenticator `create_authenticator()`.         |
| `_get_channel(target, secure=False, credentials=None)` | Create (or return the cached) gRPC channel. `target` is `host:port`. Use `secure=True` for TLS. |
| `_get_stub(stub_class)`     | Return a cached instance of `stub_class` bound to the current channel.         |
| `_call_rpc(stub_method, request, timeout=10)` | Execute a unary-unary RPC. Fires a Locust event and returns the protobuf response, or raises on error. |

### Channel Methods Detail

**`_get_channel(target, secure=False, credentials=None)`**

- `target` — `"host:port"` string, e.g. `"api.example.com:443"`.
- `secure` — when `True`, creates a `grpc.secure_channel` instead of
  `grpc.insecure_channel`.
- `credentials` — optional `grpc.ChannelCredentials`. When `secure=True` and
  `credentials` is omitted, falls back to `grpc.local_channel_credentials()`.
- Returns a `grpc.Channel` (cached per user instance — subsequent calls return
  the same channel).

**`_get_stub(stub_class)`**

- `stub_class` — a gRPC stub class generated by `protoc`.
- Returns a cached instance — repeated calls for the same stub class return
  the same object.

**`_call_rpc(stub_method, request, timeout=10)`**

- `stub_method` — a bound method of the stub, e.g. `stub.SayHello`.
- `request` — the protobuf request message.
- `timeout` — deadline in seconds (default 10).
- Returns the response message on success.
- Raises the gRPC exception on failure (after firing the event so the failure
  is recorded in Locust stats).
- Fires a Locust event with `request_type="grpc"` and `name` set to the
  method name (e.g. `"SayHello"`).

### Auth Metadata

`GrpcUser` integrates with the pluggable authenticator system:

```python
class AuthGrpcUser(GrpcUser):
    auth_provider = "oauth2"
    auth_kwargs = {
        "client_id": "my-client",
        "client_secret": "my-secret",
        "token_url": "https://auth.example.com/oauth/token",
    }
```

HTTP-style headers from the authenticator are converted to gRPC metadata
tuples `(key.lower(), value)` and attached to every RPC call automatically.

### TLS / Secure Channels

For production gRPC services that require TLS:

```python
class SecureGrpcUser(GrpcUser):
    def on_start(self):
        super().on_start()
        self._get_channel(
            "api.example.com:443",
            secure=True,
            credentials=grpc.ssl_channel_credentials(),
        )
        self.stub = self._get_stub(MyServiceStub)
```

For mutual TLS (mTLS), pass the client certificate credentials:

```python
creds = grpc.ssl_channel_credentials(
    root_certificates=open("ca.pem", "rb").read(),
    private_key=open("client.key", "rb").read(),
    certificate_chain=open("client.crt", "rb").read(),
)
self._get_channel("api.example.com:443", secure=True, credentials=creds)
```

## Full Working Example

A complete, self-contained load test for a fictional `OrderService`:

```python
"""gRPC load test for OrderService."""

from locust import between, task
from locust_templates.grpc import GrpcUser

from orders_pb2 import GetOrderRequest, ListOrdersRequest
from orders_pb2_grpc import OrderServiceStub


class OrderServiceUser(GrpcUser):
    wait_time = between(0.5, 3)

    def on_start(self):
        super().on_start()
        self._get_channel("orders.example.com:50051")
        self.stub = self._get_stub(OrderServiceStub)

    @task(5)
    def get_order(self):
        """Fetch a single order by ID."""
        request = GetOrderRequest(order_id="ord-12345")
        self._call_rpc(self.stub.GetOrder, request)

    @task(1)
    def list_orders(self):
        """List recent orders."""
        request = ListOrdersRequest(page_size=50)
        self._call_rpc(self.stub.ListOrders, request, timeout=15)
```

Run with:

```bash
locust -f orders_load_test.py --users 100 --spawn-rate 10 --run-time 10m \
  --host https://orders.example.com
```

## Best Practices

1. **Set realistic timeouts.** Unary RPC calls should have a timeout that
   reflects your SLA — default is 10 s, but adjust per operation.
2. **Cache stubs.** `_get_stub()` does this automatically. Stub creation is
   lightweight, but caching avoids channel-contention in concurrent paths.
3. **One channel per user.** The template creates one channel per `GrpcUser`
   instance. Each Locust user is a separate green thread, so this maps
   naturally to concurrent RPC connections.
4. **Use `on_stop` for cleanup.** The base `GrpcUser.on_stop` closes the
   channel; subclasses that open additional channels or resources should
   extend it.
5. **Test with insecure first.** Validate your protobuf definitions and task
   logic against an insecure local server before adding TLS to the mix.
6. **Monitor channel health.** gRPC channels are long-lived; if your test runs
   for hours, consider adding periodic health-check calls inside a low-weight
   task.
7. **Auth is per-user.** The authenticator is initialised once per simulated
   user in `on_start`. For token-based auth, ensure the token TTL covers the
   full test duration, or refresh tokens inside a task.
